# <co>Icon Gallery</c>

The <co>Icon Gallery</c> is a website made to act as a museum of custom-made icons people can download and install in their games. This is the Mod version of said website, which allows you to search and install icons with ease.

<cy>This mod is still in active development, where things are prone to changes, bugs and missing features</c>

## How do I submit an icon?

Use the tools available at the web version of the [Icon Gallery](https://iconsgallery.pages.dev/). You can also join [Asterveila's Discord Server](https://discord.gg/dceY3uvGzD) for more details.

## Contact

To report issues with the <cy>Mod version</c> or help its development, you can contact through [ML500's Github](https://github.com/MasterL500).
